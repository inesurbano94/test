# Project preferences

- Whenever creating a new website in this repo, run the `website-studio-v2` skill (invoke via `/website-studio-v2`) as part of the workflow.
- Whenever creating or changing something (a website, a page, a component, etc.), share a live preview **link** the user can click and browse (e.g. a published Artifact or a Vercel deployment) — not static screenshots — before considering the task done.

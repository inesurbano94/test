# Isaías Rocha — Personal Trainer (site novo)

**Esta é a versão nova/ativa do site**, construída na conversa com o Claude
Code (via Claude Artifacts) e publicada aqui para ligação a um hosting
gratuito (Vercel).

Ficheiro único (`index.html`) — todo o HTML, CSS, JS e imagens (em base64)
estão neste único ficheiro, sem pasta `assets/` nem build step. Basta
apontar qualquer host estático (Vercel, Netlify, GitHub Pages) para este
ficheiro na raiz do repositório.

## Ramo (branch)

Este código vive no branch `novo-site-isaias`, não no branch principal do
repositório — o branch principal tem uma versão anterior/diferente do
site (de outra sessão), deixada intacta para não perder esse trabalho. Ao
ligar este repositório a um serviço de hosting, escolher explicitamente o
branch `novo-site-isaias` como branch de produção.

## Atualizar o site

Sempre que o Claude gerar uma nova versão do `index.html`, substituir o
ficheiro neste branch (`novo-site-isaias`) — qualquer host ligado a este
branch (ex. Vercel) faz redeploy automático a cada novo commit.

# Fotos de marca (fonte/originais)

Guardar aqui as fotografias reais do Isaías e dos locais de treino, em
alta resolução, tal como recebidas — antes de qualquer corte ou
otimização para web.

As versões finais, já otimizadas e a serem usadas pelo site, ficam em
`assets/img/` (essas sim são carregadas pelo `index.html`). Este
`docs/brand/photos/` é só o arquivo de origem, para não se perder a
versão de maior qualidade.

Pendente — ver `docs/business-requirements.md` § "Por confirmar":
foto de Sobre, VivaGym, domicílio, outdoor, Contacto.

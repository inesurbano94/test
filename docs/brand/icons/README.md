# Ícones e ativos de marca

Guardar aqui ficheiros de origem (SVG, EPS, etc.) de logótipo ou
ícones de marca, caso venham a existir fora dos ícones de interface
já embutidos como `<svg>` inline em `index.html`.

Atualmente o site não tem um logótipo próprio — usa só o nome
"Isaías Rocha" em texto (`.nav__logo-name`, `.footer__logo`) e um
favicon gerado por SVG inline (ver `<link rel="icon">` em
`index.html`). Se o Isaías vier a ter um logótipo real, guardar o
ficheiro fonte aqui e o `.svg`/`.png` otimizado para web em
`assets/img/`.
